# Data Source Document

| Dataset | Source | Purpose | License / usage |
|---|---|---|---|
| Microsoft GeoLife GPS Trajectory Dataset | https://www.microsoft.com/en-us/research/publication/geolife-gps-trajectory-dataset-user-guide/ | Public human-movement trajectory reference dataset | Follow Microsoft dataset terms |
| OpenStreetMap | https://www.openstreetmap.org/ | Roads, POIs and geographical context | OpenStreetMap data is generally available under ODbL; follow attribution requirements |
| data.gov.in | https://www.data.gov.in/ | Optional public contextual/government data | Check the terms for the selected dataset |
| Synthetic CASEFILE trajectories | Generated by `generate_data.py` | Safe academic demonstration and model training | Synthetic; no PII |
| Synthetic CASEFILE case records | Generated by `generate_data.py` | Fictional investigation scenarios | Synthetic; no PII |

The supplied project guide requires public datasets plus synthetically generated case information and prohibits PII/private missing-person records.
